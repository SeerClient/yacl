# GAPS_Y2 - YACL API / impl / GUI / platform / mixins, batch Y2

Each row: the Java member, what the port / crate has now, what is needed, sites. Every site carries a
`rust: port gap (GAPS_Y2.md Gn)` mark or a doc line naming the row. "port" = the game crate (`RustSrc`) must grow an
API; "converter" = fabric2seer must generate it; "compat" = `src/compat.rs`.

## Not gaps (decided, documented at the site)

* `Item` values are `compat::JavaRef<Item>` (identity `PartialEq`, `Send + Sync`); `ItemRegistryHelper` answers it and
  the two `ItemTypeAdapter`s use it (closes Y1's G7).
* `YACLPlatform.getEnvironment()` is `Env::Client`, `isDevelopmentEnv()` is `false`, `getConfigDir()` is the port's
  config dir (closes Y1's G6).
* An `Option` and its controller reference each other (`Arc` cycle): options live as long as their config, as in
  Java; every GUI object that points back at its owner (widget -> screen, entry -> list, child entry -> group
  separator, popup -> entry widget, tab -> screen) holds a `Weak`.
* `CyclingListController(option, values)` without a formatter: Java formats with `Object.toString()`; Rust has no
  universal `toString`, so that constructor takes the `to_string` function (`EnumController` uses `JavaEnum::name`,
  which is an enum's `toString()` unless the enum overrides it).
